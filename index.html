Generador de Addons

Genera, revisa y empaqueta Behavior Packs y Resource Packs para Minecraft Bedrock.
Esta versión corrige manifiestos JSON mal formados por la IA y valida los archivos antes de empaquetarlos. La revisión estructural no sustituye una prueba dentro de Minecraft.
La clave se guarda en el almacenamiento local de este navegador (no está cifrada). Evita usar este archivo en dispositivos compartidos.
Consulta el catálogo de tu cuenta y elige un modelo general compatible. La selección es heurística, no una prueba de rendimiento.

🔊 Gemini TTS: clave API necesaria para generar voces

Opcional: solo se usa si generas voces. Si el addon no necesita audio, Gemini no se utiliza.
La clave se guarda localmente en este navegador. También se usará en la sección de generación de audios del editor.

Editor de archivos

Selecciona un archivo, edítalo y guarda los cambios antes de empaquetar.
Si tu addon tiene Behavior Pack y Resource Pack, exporta cada uno por separado como .mcpack o descarga el conjunto como .mcaddon.

🔊 Voces reales para los diálogos (Gemini TTS)

Gemini genera audio; el generador lo convierte a OGG Vorbis y lo agrega al Resource Pack. Cada línea consume una solicitud de audio. Necesitas una clave Gemini con acceso a TTS.
Genera 3 audios, espera este tiempo (60 s = 1 minuto) y sigue con los siguientes 3.
Los sonidos se guardan en ResourcePack/sounds/voices/ y se registran en sounds/sound_definitions.json. El addon también debe invocar los eventos villager_voice.dialogue_001, villager_voice.dialogue_002, etc.; el generador crea el mapa para conectarlos con la lógica de diálogo.
